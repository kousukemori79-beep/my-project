# ユーザー共通の指示（CLAUDE.md サンプル）

このファイルは参考用のサンプルです。実際の内容は、現在お使いのPCの
`~/.claude/CLAUDE.md` を `sync push` で取り込むと、ここが本物に置き換わります。

Claude Code 全体に効く共通指示をここに書きます。例:

- 回答は日本語で行う。
- コードを変更したら、変更の理由を簡潔に説明する。
- 不明点は勝手に進めず、先に確認する。

> 秘密情報（APIキー・トークン等）はこのファイルに書かないでください。
> 機密値は `~/.claude/settings.local.json`（同期対象外）で管理します。
